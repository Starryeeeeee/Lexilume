# Lexilume

一个可自行部署的单词学习网站，按记忆曲线调度复习。纯静态，无后端，数据存在本机浏览器，可配置跨设备同步。

## 特点

- **调度模型**：每个词维护难度 D 与稳定度 S，保留率按 `R = 1/(1 + t/9S)` 计算，目标保留率 90% 时下次复习时间恰好是 `上次 + S 天`。答错只缩水不清零。
- **固定配额**：每天新学与复习的条数固定，复习不排队堆到某一天。
- **学习流程（百词斩式）**：先复习到期词 → 新学（词卡看完点「继续」，立刻做「看词选义」巩固这道词，答完自动进入下一个词）→ 拼写模式（全部新词学完后询问是否进入；只显示中文释义并自动朗读单词，读音按钮兼作提示；拼错就地亮出正确拼写、重听读音后重新拼，不跳词，首次计分、重拼不计分；可跳过，跳过即完成今日学习）。
- **答对对比释义**：选择题答对后，每个选项直接叠显「英文在上、中文在下」，停留 2.6 秒可读完（点击可提前继续），方便对比记忆（练习模式同样生效）。
- **练习模式**：学有余力时在首页进入，随机抽 10 个已学词，可选「看词选义」或「看义选词」两种方式；答错会展示正确答案；练习不计入学习进度与统计。
- **答错退回**：学习和复习中答错的词立刻退回该词介绍页，看完点继续，该词稍后重考，最多重考两次。
- **题型**：看词选义（基础）+ 看义选词（设置里可开关）。新词看完卡片立刻做「看词选义」；复习题按更弱的记忆通道选择题型，看义选词会在复习阶段出现。
- **多种词表**：可切换词表，支持粘贴 CSV/TSV 导入，进度按词表分别记录。
- **复盘**：掌握度分布、未来 30 天复习量预测、24 周打卡热力图、遗忘风险榜、错词本。

## 使用方式

### 1. 直接打开（U 盘 / 离线）

把整个目录拷到任意位置，双击 `index.html`。不需要装任何东西，不需要联网。

### 2. 部署成网站（GitHub Pages）

在 GitHub 建一个空仓库，然后：

```bash
git remote add origin ssh://git@ssh.github.com:443/<用户名>/Lexilume.git
git push -u origin main
```

到仓库 Settings → Pages，Source 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`，保存后等一分钟。

访问 `https://<用户名>.github.io/Lexilume/`。手机浏览器可以「添加到主屏幕」，装成 App 之后断网也能用。

## 登录

打开网站的第一步是登录：粘贴访问令牌（与跨设备同步用的是同一个 Fine-grained token）。没有令牌无法进入功能界面；登录成功后本机会记住，之后打开直接进入。令牌失效会自动回到登录页；退出登录在「设置 → 跨设备同步」里。离线时已登录的设备可以照常学习，只是同步会暂停。

注意：这是纯前端静态站，登录门挡的是「直接使用」；懂技术的人仍可能绕过界面，且公开仓库里的 progress.json 本身可被读取。介意后者就把数据文件指向私有仓库。

## 跨设备同步

登录用的令牌同时就是同步凭证，登录后同步即已开启。数据默认只存在「打开它的那台浏览器」里，换设备不会跟过去；要跨设备，用仓库文件当数据后端：

1. 生成 token：GitHub → Settings → Developer settings → **Fine-grained personal access tokens** → Generate new token。
   - Repository access 只选 `Lexilume` 这一个仓库
   - Permissions 里只给 **Contents: Read and write**
2. 打开网站 → 设置 → 跨设备同步，仓库填 `<用户名>/Lexilume`，令牌粘贴进去，点「保存并同步」。

之后每次答题会攒二十多秒自动提交一次，打开页面时也会自动拉取。合并规则是**每个词取最后一次复习时间更晚的那份**，两台机器各学各的，不会互相覆盖。内容没有变化时不会向仓库提交，避免产生空 commit。

同步的两个已知边界：

- **清空不传播**：本机「清空当前词表进度」后，下次同步会从远端把旧进度合并回来（合并只做并集，删除没有语义）。要真正清掉，请在设置里「断开」同步后清理，或同时清掉远端文件。
- **同日双机计数**：每日学习日志按天取各字段较大值。两台电脑**同一天**各学 20 词，合并后记 20 而不是 40。交替使用不受影响。

注意：仓库若为公开（Pages 免费版要求公开），这份 `progress.json` 也会被公开读取。介意的话把数据文件指向另一个私有仓库即可，设置里可以改仓库名。

## 导入词表

每行一个词，用逗号或 Tab 分隔，字段顺序：

```
word, 音标, 词性, 释义, 例句, 例句翻译
```

音标、词性、例句、例句翻译都可以留空，只写 `word, 释义` 也能导入。

## 目录

```

assets/style.css      样式（新拟态）
src/srs.js            调度内核（纯函数，无 DOM 依赖）

src/quiz.js           出题与题型路由

src/app.js            界面与会话流程
data/books.js         词库
sw.js                 离线缓存（改资源后记得 bump CACHE 版本号）
tools/selftest.js     核心逻辑自检：node tools/selftest.js
tools/make-icons.js   重新生成图标
```

## 数据

全部保存在浏览器 localStorage 的 `wl.*` 键下。换设备或清缓存前，先在「设置 → 导出备份」存一份 JSON；恢复时选「从备份恢复」。
